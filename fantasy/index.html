Fantasy AI Manager

I was in too many fantasy football leagues, and managing them took hours I don't have in college. So I built a bot that runs my teams end to end. I don't open the ESPN app anymore.

The one rule

Plain code makes every decision. The AI only labels news and writes explanations, and it's never allowed to invent a number.

  • CodeDecides. Player values, lineups, waiver and trade scores.
  • AILabels and explains. Turns news and my texts into small labels.
  • MeApproves. Adds, drops and trades wait for my reply.

How it works

02

Most of it is plain Python. The AI shows up in two places, and both are boxed in.

  1. 1 · ScheduleCode
    Wake up

    Runs on my Mac. A full run Thursday at 2pm, a recheck Saturday at 2pm and a last check Sunday at 11:45am, after inactives. It catches up if the laptop was asleep.

  2. 2 · ReadData
    Read ESPN and the news

    ESPN has no public API, so it uses the same private endpoints ESPN's own site uses. Plus news feeds, Sleeper, Vegas lines, weather and usage stats.

  3. 3 · LabelAI
    Label the news

    Each news item becomes a tiny JSON label: status, practice, role change, a short note. Anything malformed gets dropped.

  4. 4 · DecideCode
    Make every call

    Labels turn into capped number changes. Then code values every player and searches for the best lineup, adds and trades.

5a · On its ownCode
Lineups and IR

Saved on ESPN with no reply needed. Then it texts me what moved and why, with the source for every reason.

  1. Set lineup
  2. Move IR
  3. Text me
5b · Waits for meMe
Adds, drops, trades

Texted with pros, cons and a verdict. I reply "approve 15". Free text like "start Mitchell" gets an AI intent label, and code does the rest.

  1. Queue
  2. Text me
  3. My reply
  4. Re-check
  5. Send
Slow on purposeCached reads, random gaps, at most 3 writes a run and 6 a day per league. Any error pauses that league for a day and texts me.
Re-check, then sendApproving re-reads the league first. If a player moved, got picked up or locked, nothing is sent.
Only my teamEvery request is checked against my team ID before it goes out, test runs included.
No made-up numbersIf an AI-written note has a number that isn't in the facts, the note gets thrown out.

I built it with Claude Code, starting Sep 30, 2026. It's about 8,700 lines of Python with 23 test files. The ESPN request shapes follow two open-source projects, heyitaki/espn-fantasy-football-mcp and jwulff/fantasy-sports.
